# Reference houses

Whole houses kept for **inspiration or as a layout base**. Not synced to Studio, not committed.

Look at them, measure them, copy the room proportions. Don't ship them. A house only enters the game
by being curated into `../approved-imports/houses/` with a row in [`../ASSET_MANIFEST.md`](../ASSET_MANIFEST.md).

Contents are gitignored — this folder is yours locally and stays empty for everyone else.
